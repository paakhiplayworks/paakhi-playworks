# Paakhi Playworks — static website

A responsive, single-page website inspired by the supplied homepage artwork. Built with plain HTML, CSS and JavaScript; no build step or framework is required.

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in a modern browser.

## Publish on GoDaddy (if you have Web Hosting/cPanel)
1. Sign in to GoDaddy and open **My Products**.
2. Open **Web Hosting → Manage → File Manager**.
3. Open the website root directory. For a primary domain on cPanel this is usually `public_html`.
4. Upload the ZIP, extract it, and make sure `index.html`, `styles.css`, `script.js`, and the `assets` folder are directly in the root directory (not nested inside another folder).
5. Visit your domain. If it doesn't load, check the domain's DNS and hosting setup.

Official GoDaddy guide: https://www.godaddy.com/en-in/help/upload-files-using-my-web-hosting-cpanel-file-manager-3239

## Before launch
- Replace the temporary cropped artwork in `assets/` with original high-resolution character and game artwork when available. The images in this starter are crops from the supplied design reference.
- Replace the `Explore Games` and Google Play placeholder links with real game/store URLs when your apps are published.
- Update `hello@paakhplayworks.com` to the email address you want to use.
- If you use a GoDaddy domain only (without a hosting plan), domain registration alone does not serve these files; you will need a hosting service or a GoDaddy Website/hosting plan.
